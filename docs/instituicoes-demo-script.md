# Script de demo comercial — Módulo Instituições (15 min)

**Público:** diretor, coordenador, gestor de rede, mantenedor  
**Pré-requisito:** Waves W1–W3 concluídas (mínimo); W5 para slide de rede

---

## Minuto 0–2 — Problema

> "Vocês sabem quem parou de estudar esta semana? Em qual conteúdo a turma inteira está travada? O Broto responde isso em tempo real — sem planilha."

---

## Minuto 2–7 — Camada Professor (conta `teacher@demo`)

1. Login admin → turma já aparece (zero config).
2. **Lista de alunos:** apontar cores — verde (engajado), amarelo (streak quebrado), vermelho (sumido).
3. **Habilidades da turma:** tópico com p_know baixo em massa → "retomar em aula, não só mandar aluno estudar sozinho".
4. Clicar aluno → histórico recente.
5. **Marcar acompanhamento** → "vira sinal para coordenação sem burocracia".

**Frase de fechamento:** "O professor abre isso em 30 segundos entre aulas."

---

## Minuto 7–11 — Camada Escola (conta `coordenador@demo`)

1. Ranking de turmas por engajamento (% ativos 7 dias).
2. **Alertas de risco** — alunos com queda abrupta, ordenados por severidade.
3. **Export PDF** → "material que você leva para o conselho ou diretoria".

**Frase de fechamento:** "Alerta precoce de abandono — não é promessa, é dado agregado."

---

## Minuto 11–14 — Camada Rede (conta `rede@demo`, Wave W5)

1. Comparativo entre escolas — números grandes (projetor).
2. **Índice de risco de abandono** por escola.
3. Deixar claro: "Arquitetura pronta para secretaria; dados de demo rotulados internamente."

**Frase LGPD (obrigatória se perguntarem):**

> "Dados isolados por instituição desde o banco (RLS). Na visão de rede, mostramos agregados — nome de aluno só para quem tem vínculo pedagógico direto. Temos trilha de auditoria de acesso a dados sensíveis."

---

## Minuto 14–15 — Fechamento comercial

> "Em 4 semanas vocês têm turmas reais no painel. Não precisamos integrar SGP no dia 1 — CSV e código de turma bastam para começar."
