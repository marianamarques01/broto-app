    Step 1 — Read all four tsconfig files carefully. Note which compilerOptions are shared vs app-specific.

    Step 2 — Create `/tsconfig.base.json` at repo root with shared options (per D-10 and Pattern 3 in RESEARCH.md):
    ```json
    {
      "compilerOptions": {
        "target": "ES2020",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "strict": true,
        "skipLibCheck": true,
        "noFallthroughCasesInSwitch": true,
        "isolatedModules": true,
        "moduleDetection": "force",
        "noEmit": true,
        "esModuleInterop": true
      }
    }
    ```

    Step 3 — Update `apps/web/tsconfig.json` to extend base. Keep ONLY web-specific options:
    ```json
    {
      "extends": "../../tsconfig.base.json",
      "compilerOptions": {
        "lib": ["ES2020", "DOM", "DOM.Iterable"],
        "useDefineForClassFields": true,
        "allowImportingTsExtensions": true,
        "jsx": "react-jsx",
        "noUnusedLocals": false,
        "noUnusedParameters": false,
        "baseUrl": ".",
        "paths": { "@/*": ["./src/*"] }
      },
      "include": ["src"]
    }
    ```

    Step 4 — Update `apps/admin/tsconfig.json` the same way (same structure as web — check actual content first and mirror it).

    Step 5 — Update `apps/mobile/tsconfig.json` (per Pattern 3 and Pitfall #7 in RESEARCH.md — preserve expo-specific settings):
    ```json
    {
      "extends": "../../tsconfig.base.json",
      "compilerOptions": {
        "lib": ["ES2020"],
        "jsx": "react-native",
        "allowSyntheticDefaultImports": true,
        "resolveJsonModule": true,
        "baseUrl": ".",
        "paths": { "@/*": ["./*"] }
      },
      "include": ["**/*.ts", "**/*.tsx", "nativewind-env.d.ts", "svg.d.ts"]
    }
    ```
    CRITICAL: Retain `allowSyntheticDefaultImports: true` and `resolveJsonModule: true` — these are Expo-required settings.

    Step 6 — Update `packages/shared/tsconfig.json` to extend base, retaining any outDir/declaration settings present in the current file.

    Step 7 — Verify TypeScript compiles cleanly:
    ```

    npx tsc --noEmit --project apps/admin/tsconfig.json
    npx tsc --noEmit --project apps/mobile/tsconfig.json
    ```
    Fix any errors before proceeding. Common issue: if `noEmit: true` is in base but a specific tsconfig needed it absent, override it per-app.

    Step 8 — Commit:
    ```
    git add tsconfig.base.json apps/web/tsconfig.json apps/admin/tsconfig.json apps/mobile/tsconfig.json packages/shared/tsconfig.json
    git commit -m "chore(tooling): add root tsconfig.base.json, all apps extend it (TOOL-01)"
    ```
