    Read `eslint.config.mjs` fully. It is an ESLint 9 flat config using `tseslint.config(...)`. The existing blocks must NOT be modified — append two new blocks inside the `tseslint.config()` call, before the closing parenthesis.

    Add these two blocks (per D-12, D-13, D-14 and Pattern 2 in RESEARCH.md):

    BLOCK 1 — packages/shared platform boundary guard (TOOL-05):
    ```javascript
    // packages/shared must remain platform-agnostic (TOOL-05, D-12)
    {
      files: ['packages/shared/src/**'],
      rules: {
        'no-restricted-imports': [
          'error',
          {
            patterns: [
              {
                group: ['react', 'react-dom', 'react-native', 'expo*', '@react-native*'],
                message:
                  'packages/shared must remain platform-agnostic — use adapter pattern for platform APIs',
              },
            ],
          },
        ],
      },
    },
    ```

    BLOCK 2 — no-floating-promises across all app code (TOOL-06):
    ```javascript
    // no-floating-promises prevents unhandled async errors (TOOL-06, D-13)
    {
      files: ['apps/*/src/**/*.{ts,tsx}', 'apps/mobile/**/*.{ts,tsx}'],
      languageOptions: {
        parserOptions: {
          project: true,
          tsconfigRootDir: import.meta.dirname,
        },
      },
      rules: {
        '@typescript-eslint/no-floating-promises': 'error',
      },
    },
    ```

    CRITICAL: The `parserOptions.project: true` is REQUIRED for `no-floating-promises` to work (per Pitfall #3 in RESEARCH.md). Without it, the rule silently fires on nothing.
    CRITICAL: Do NOT add `project: true` globally — scope it only to this block to avoid slowing all linting.

    After editing, run ESLint to verify the rules are active:
    ```
    npm run lint 2>&1 | head -30
    ```
    The lint run may produce new errors (floating promises that exist in the codebase) — that is EXPECTED and correct. The goal is that the rules are ACTIVE, not that there are zero violations.

    Commit:
    ```
    git add eslint.config.mjs
    git commit -m "chore(tooling): add no-restricted-imports for shared, no-floating-promises for apps (TOOL-05, TOOL-06)"
    ```
